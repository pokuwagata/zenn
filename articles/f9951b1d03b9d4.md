## EasyMotion

EasyMotion はデフォルトで `<Leader> + <Leader> + s` でトリガーできますが、キー入力が多いので`<Leader> + f` に変更しています。

```json:settings.json
{
  "vim.normalModeKeyBindingsNonRecursive": [
    {
      "before": ["<Leader>", "f"],
      "after": ["<Leader>", "<Leader>", "s"]
    }
  ]
}
```
