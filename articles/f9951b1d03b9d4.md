私は VSCode Vim を 2017 年頃から業務で使用しています。キーバインドは基本的にはデフォルト設定ですが、使いやすいように一部変更・追加しています。

この記事では、私の VSCode Vim のおすすめキーバインド設定の一部をご紹介します。

なお、`<Leader>` キーはスペースキーを使用しています。

## 空行挿入

VSCode Vim では、ノーマルモードから空行を挿入してノーマルモードに戻る際にはインサートモードに1度切り替える必要があります。

デフォルトでは `o` -> `Esc` でカーソルの次の行に空行を挿入してノーマルモードに戻ることができます。

ノーマルモードに戻るためのキー入力が少し煩わしいので、`<Leader> + o` で空行を挿入できるように設定しています。(`O` も同様)

```json:settings.json
{
  "vim.normalModeKeyBindingsNonRecursive": [
    { "before": ["<Leader>", "o"], "after": ["o", "<ESC>"] },
    { "before": ["<Leader>", "O"], "after": ["O", "<ESC>"] },
  ]
}
```

キーの入力数は同じですが、個人的にはこちらの方が快適です。

## ファイル保存

デフォルトでは、`:w` でファイルを保存できます。

`Enter` も含めるとキー入力数は 3 で少し多いので、`<Leader> + w` で保存できるように設定しています。

```json:settings.json
{
  "vim.normalModeKeyBindingsNonRecursive": [
    {
      "before": ["<Leader>", "w"],
      "after": [":", "w", "<CR>"],
    },
  ]
}
```

コーディングでもドキュメント編集でも保存は頻繁に行うので、キー入力数が 2 かつ左手で完結するように設定するとかなり快適です。

## EasyMotion

EasyMotion はデフォルトで `<Leader> + <Leader> + s` でトリガーできますが、キー入力数が多いので`<Leader> + f` に変更しています。

```json:settings.json
{
  "vim.normalModeKeyBindingsNonRecursive": [
    {
      "before": ["<Leader>", "f"],
      "after": ["<Leader>", "<Leader>", "s"]
    }
  ]
}
```

キー入力数が 3 から 2 に減ったことで、EasyMotion の利用頻度が増えたように感じます。

## 同一行内での移動

VSCode Vim では折り返しを含む長い1行内でカーソルを下に移動させるためには `j` ではなく `gj` と入力が必要です。

```txt
改行文字を含まない長い行改行文字を含まない長い行改行文字を含まない長い行改 // 👈 この行で `gj` を入力すると
行文字を含まない長い行改行文字を含まない長い行改行文字を含まない長い行 // 👈 この行にカーソルが移動
```

ドキュメントを書く場合は VSCode 内で折り返しが頻繁に発生するので、`gj` を `j` に、`gk` を `k` に変更しています。

```json:settings.json
{
  "vim.normalModeKeyBindingsNonRecursive": [
    {
      "before": ["j"],
      "after": ["g", "j"],
    },
    {
      "before": ["k"],
      "after": ["g", "k"],
    },
  ]
}
```

この設定で、以下のようにカーソル移動できます。

```txt
改行文字を含まない長い行改行文字を含まない長い行改行文字を含まない長い行改 // 👈 この行で `j` を入力すると
行文字を含まない長い行改行文字を含まない長い行改行文字を含まない長い行 // 👈 この行にカーソルが移動
```

ただし、間に折り返し行を含む場合に相対行番号移動はズレてしまう欠点があるのでご注意ください。

例:

以下のテキストでカーソル位置から `2j` を入力すると「次の行」ではなく折り返し2行目に移動してしまいます。（`j` を `gj` に変更しているため）

行頭は相対行番号を示します。

```txt
1: // 👈 この行で `2j` を入力したら 3行目に移動して欲しいが...
2: 改行文字を含まない長い行改行文字を含まない長い行改行文字を含まない長い行改 // VSCode の折返し位置
行文字を含まない長い行改行文字を含まない長い行改行文字を含まない長い行 // 👈 カーソルはこの行に移動
3: 次の行
```
