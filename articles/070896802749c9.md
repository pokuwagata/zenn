## はじめに

私は開発業務で VSCode を 10 年弱ぐらい使用してきましたが、2~3 ヶ月前に VSCode から LazyVim に移行しました。

業務で使用できるぐらいには LazyVim に慣れてきたので、同じく LazyVim に移行を検討されている方や最近移行した方向けに、重要なキーバインドや Plugin を紹介します。

## 移行理由

- Claude Code を使う時間が長い(VSCode 内のターミナルだと手狭)
  - VSCode ではなく、ターミナルを作業の中心に置きたい
- VSCode の起動が遅く感じる
- 元々 Vimmer で、VSCode も Vim キーバインドで使用していた

可能なら Vim で開発したいという気持ちは前からあったので、重い腰を上げて移行してみることに。

0 から Vim をカスタマイズする元気と時間はもうないので、LazyVim を使うことにしました。

## 前提

- mac OS
- LazyVim デフォルトキーバインド
- 主に TypeScript とマークダウンの読み書きに使用
  - フロントエンドエンジニアです

## 扱わないこと

- 一般的な Vim キーバインド

## コードリーディング

コードを読む際によく使う操作をまとめました。VSCode のキーバインドも記載しています。

### シンボル

| 内容             | LazyVim              | VSCode            |
| ---------------- | -------------------- | ----------------- |
| シンボルリスト   | `leader` + `s` + `s` | `cmd` + `p` + `@` |
| シンボルリネーム | `leader` + `c` + `r` | `F2`              |
| 参照元リスト     | `g` + `r`            | `F12`             |
| 定義ジャンプ     | `g` + `d`            | `F12`             |
| 型定義ジャンプ   | `g` + `y`            | `F12`             |

### バルーン

| 内容            | LazyVim              | VSCode    |
| --------------- | -------------------- | --------- |
| Lint エラー表示 | `leader` + `c` + `d` | `g` + `b` |
| 型定義表示      | `K`                  | `g` + `h` |

### grep

[fzf-lua](https://github.com/ibhagwan/fzf-lua) を使用しています。

| 内容                            | LazyVim                                            | VSCode                  |
| ------------------------------- | -------------------------------------------------- | ----------------------- |
| カレントディレクトリ配下を grep | `leader` + `/`                                     | `cmd` + `shift` + `f`   |
| グロブパターンで絞り込み        | 検索ワードとセットで記述 例: `test -- src/**/*.ts` | `含めるファイル` に記述 |

## ファイル

### explorer

ファイルエクスプローラーは [Yazi](https://github.com/sxyazi/yazi) を使用しています。 [yazi.nvim](https://github.com/mikavilpas/yazi.nvim) で nvim からも起動できます。

| 内容             | LazyVim        | VSCode                             |
| ---------------- | -------------- | ---------------------------------- |
| サイドバーに表示 | `leader` + `e` | `cmd` + `shift` `e` or `cmd` + `b` |
| yazi.nvim 起動   | `leader` + `-` | なし                               |

### picker

| 内容          | LazyVim            | VSCode      |
| ------------- | ------------------ | ----------- |
| picker を表示 | `leader` + `space` | `cmd` + `p` |

### diff

| 内容                         | LazyVim           | VSCode                                           |
| ---------------------------- | ----------------- | ------------------------------------------------ |
| 2 ウィンドウ間の diff を表示 | `:windo diffthis` | コマンドパレットで `Compare Active File With...` |

## git

基本的な git 操作は [lazygit](https://github.com/jesseduffield/lazygit) で行っています。

| 内容                               | LazyVim              | VSCode                      |
| ---------------------------------- | -------------------- | --------------------------- |
| lazygit 起動                       | `leader` + `g` + `g` | なし                        |
| ファイルの変更履歴を表示           | `leader` + `g` + `f` | なし                        |
| コミット履歴一覧を表示             | `leader` + `g` + `c` | なし                        |
| blame (該当行の変更履歴一覧を表示) | `leader` + `g` + `b` | なし(直近1件はフロート表示) |

## 補完

[blink.cmp](https://github.com/saghen/blink.cmp) のキーバインドを変更し VSCode の操作性に合わせています。

```lua/plugins/blink.cmp.lua
return {
  {
    "saghen/blink.cmp",
    opts = {
      keymap = {
        preset = "super-tab",
      },
    },
  },
}
```

| 内容           | LazyVim      | VSCode       |
| -------------- | ------------ | ------------ |
| 補完候補を選択 | `ctrl` + `n` | `ctrl` + `n` |
| 補完候補を決定 | `tab`        | `tab`        |

## プレビュー

以下の Plugin を使用しています。特に VSCode に比べて不便は感じていません。プレビューの起動は VSCode より少し遅く感じます。

| 対象     | Plugin                                                                      | コマンド          |
| -------- | --------------------------------------------------------------------------- | ----------------- |
| markdown | [arto.vim](https://github.com/arto-app/arto.vim)                            | `:arto`           |
| Swagger  | [swagger-preview.nvim](https://github.com/vinnymeller/swagger-preview.nvim) | `:SwaggerPreview` |
| Mermaid  | [mermaid.nvim](https://github.com/kevalin/mermaid.nvim)                     | `:MermaidPreview` |

## 終わりに

Live Share で複数人で同時作業する場合だけは VSCode を使っています。この機能は明確に VSCode の優位性かなと感じます。

それ以外は LazyVim で良い感じに業務できています。
